Sopko — App Map & Architecture Guide

Reference Snapshot: Commit de5e300

Sopko is an offline-capable, mobile-first inventory and sales tracker designed for single-owner kirana (grocery) shops. It runs 100% in the browser using localStorage, with integer paise representation for financial accuracy and zero backend dependencies.

The Core Flow: Recording a Sale

Tap "Sell ₹X" → Atomically appends to sales[] ledger & decrements item.currentStock → Instant UI re-render

Key Code Tour Stops

1. UI Trigger & Boundary: src/components/SellBottomSheet.jsx

Controls the quantity stepper, clamps values to item.currentStock, displays the amber "Only N left in stock" notice, and prevents overselling.

2. The Store Ledger: src/services/storage.js

Contains recordSale(), addStock(), and addItem(). All state mutations write to both an item's cache and an immutable transaction ledger in localStorage.

3. Real-Time Dashboard: src/components/Header.jsx

Dynamically filters today's sales using the device's local calendar day, sums the revenue in paise, and displays the low-stock status pill (swapping to a compact header on Stock In).

"To Change This, Start Here"

  • Modify the default low-stock threshold (5): In src/services/storage.js (line 104) and src/components/NewItemModal.jsx (line 9).
  • Add or adjust sample kirana items: Edit src/services/sampleData.js to customize products and past 7-day sales.
  • Customize the warm color palette: Check src/styles/tokens.css (e.g. --bg-banner, --btn-primary-bg).
  • Add a new export column or format: Update downloadCSV() in src/services/storage.js.
A Practice to Reuse

Isolate storage into a single ledger service. By routing all state changes through src/services/storage.js rather than writing directly to localStorage from individual React components, our app maintains clean atomic data integrity. When we added "Reset all data" and restock history, we updated only the service file without breaking any UI components. This same ledger design will make plugging in Google Sheets cloud sync in v2 trivial.
